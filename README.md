# Concept sites

Two concept websites built to show design and motion for film and commercial production work.
The companies, people and clients are fictional. Footage: Pexels (Pexels licence).

- Vesper Row, a production company: `/vesper-row/`
- Mira Castellane, a commercial director: `/mira-castellane/`

Astro, GSAP, Lenis and a small WebGL shader. Build: `pnpm install`, then `pnpm build`.
Add `?motion` to any URL to see full motion on a machine set to reduce motion.
